# imp12 — Диета промптов Мариям: SOUL, память, кроны, новости

Кодер: Opus. НЕ НАЧИНАТЬ до отчёта `tasks/sol/fix15.report.md` — там замеры
фактического промпта и причина сбоя 27–30.08. Если причина окажется иной,
замеры всё равно использовать здесь.

## Зачем

Бюджет ~$35/мес против рамки $10–15. Системный промпт раздут: SOUL 33 193
байта (после чистки imp07-opus было 28 698 — месяц точечных фиксов наслоил
правил), память профиля выросла за месяц эксплуатации, схемы 30 инструментов
в каждом запросе. Вероятно, это же уронило бота (fix15).

## Задание

1. **SOUL ≤ ~20К байт** без потери смысла. Неприкосновенно: четыре жёстких
   правила (узбекская кириллица; голос; цифры только из tools; религия только
   из источников), §10 медицинская безопасность, §11 эмоции, выбор
   инструментов (`get_monthly_budget_status` для «сколько потратили за месяц»,
   `get_tashkent_prayer_times` + хиджра, закрытие обязательств §8).
   Сжимать: §5.2 — 54 строки контракта форматов, §8 — 47, §9 — 46; слить дубли
   (в §9 правило «источник только из ответа tool» стоит дважды — отмечено ещё
   при проверке fix08-terra), снять наслоения страховок, где одно правило
   покрывает другое. Каждое удаление — обоснование в отчёте (как в imp06-opus).
2. **Память профиля:** разовая ревизия MEMORY.md/USER.md на VPS — оставить
   компактные семейные факты (родня в координатах Ойижон, 8 внуков,
   обязательства, план), старое и дубли — в архивный файл вне промпта.
   Предложить потолок размера и механизм, чтобы через месяц не разрослось
   снова; механизм согласовать в чате до внедрения.
3. **Кроны → no_agent:** простые job'ы по оценке imp07-opus раздел 6
   (~25 000 ток/день экономии). Отпечатки обязательны: пересчёт `--apply` +
   гейт `--check` (процедура fix04-opus), иначе CRON_JOB_UNTRUSTED и пустые
   сообщения.
4. **`get_daily_news` → топ-3 пункта** (~2 500 ток/turn, оценка imp07).
   Backend + тесты.
5. **Замер до/после:** байты и токены собранного system prompt (state.db),
   стоимость дня по биллингу провайдера, прогноз месяца. Цель — движение к
   $10–15, цифрами.

## Процедура

SOUL: пересчитать SHA, права 0444, тесты, deploy по DEPLOY.md с бэкапом и
cron-гейтом, откат при FAIL. Live-приёмка на живом боте (mariyam_test для
поведения модели непригоден): запись расхода, отчёт месяца (колонки
Режа/Қолгани), намаз + хиджра, новости, один семейный вопрос. Формат ответов
для мамы измениться не должен. Commit+push; реестр обновляет архитектор.
