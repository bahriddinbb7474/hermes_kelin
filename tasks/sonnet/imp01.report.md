# imp01 — отчёт

## Этап 1 — скрипт деплоя

`deploy/scripts/deploy_soul_ac692b6e.sh`. Финальная версия (после правки
архитектора) не встраивает текст SOUL: проверяет SHA уже доставленного
отдельно файла (`SOURCE`), затем бэкап (0600, путь печатается), снимает 0444,
пишет, возвращает 0444, сверяет SHA, перезапускает только
`hermes-gateway-mariyam_oyijon.service`, откатывается при любом расхождении.
Идемпотентен. Позже (в imp02) параметризован по SHA через
`OLD_SHA_EXPECTED`/`NEW_SHA_EXPECTED`, чтобы не плодить копии под каждый
коммит.

Локально прогнаны все ветки на фейковом `$HOME` (без реальных данных):
успешный деплой, идемпотентный повтор, останов при чужом текущем SHA,
останов при неверном доставленном файле — все совпали с ожиданием.

Промежуточный путь доставки менялся дважды по ходу задачи:
1. изначально скрипт вставлялся вставкой в открытую SSH-сессию заказчика —
   не подошло по размеру (33 КБ с embedded SOUL);
2. переделан на доставку файла через `scp` отдельно от короткого скрипта
   (~2.7 КБ) — работало, но требовало ручной вставки заказчиком;
3. заказчик выдал отдельный SSH-ключ (`sonnet_hermes`) — после этого доставка
   и запуск выполнялись мной напрямую по SSH, без участия заказчика в
   пошаговых командах.

`food.ready_food` — 0 записей, все четыре новые подгруппы присутствуют с
ожидаемыми суммами. ИТОГО не совпадает с числом из задачи (1 712 208 при 44
записях) — заказчик подтвердил, что это устаревшая цифра: с 2 по 3 августа
Ойижон дописала 4 расхода на 115 000. Состав (не сумма) подтверждает миграцию
007 и правку SOUL fix12-terra — **PASS**.
