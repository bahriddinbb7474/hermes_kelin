# Инструкция для кодеров (Sol, Terra, Luna, Opus, Sonnet)

Постоянные правила. Читать при каждой задаче.

## Как получить задачу
Заказчик пишет тебе только id, например: «doc01 — do it».
Твой файл задачи: `tasks/<твоё-имя>/<id>.md`
(Sol → `tasks/sol/`, Terra → `tasks/terra/`, Luna → `tasks/luna/`,
Opus → `tasks/opus/`, Sonnet → `tasks/sonnet/`).
Задача самодостаточна — весь контекст внутри файла. Ничего сверх задачи не делать.

## Как ответить (обязательно, каждый раз)
1. Отчёт — файл рядом с задачей: `tasks/<твоё-имя>/<id>.report.md`.
   Содержание: что сделано, изменённые файлы, hash коммита, результаты проверок,
   что НЕ сделано и почему (если остановился).
2. В чат заказчику — 2–3 предложения простым русским: суть результата.
   Без технических деталей, они в отчёте.

## Правила
- Выход за рамки задачи запрещён (рефакторинг «заодно», лишние файлы, чужие статусы).
- Коммитить только свои изменения, файлы добавлять поимённо (`git add <file>`).
- Если задача неясна или блокирована — остановиться, написать это в report и в чат.
