## Выбранный путь

Выбран вариант **А — настраиваемый метод Aladhan**. Это сохраняет один
структурированный JSON-запрос, суточный cache/stale-контракт и хиджру в том же
ответе, без хрупкого HTML-парсинга. Параметры подобраны по официальному
календарю Fatvo.uz: `method=99`, `school=1` (Hanafi),
`methodSettings=15.5,null,15.5`,
`tune=0,0,-5,5,0,5,0,-4,0`.

Официальный публичный API Fatvo (`https://api.fatvo.uz/v1/prayer-times`) был
использован для сезонной сверки расчёта, а опубликованные календарные поправки
— для восхода, пешина, шома и хуфтона. Источник в tool-ответе называется
честно: `Aladhan (custom settings matched to Fatvo.uz)`, метод —
`Custom Uzbekistan: 15.5°/15.5° + Fatvo.uz ihtiyot`.

`mariyam_test`, с явно зафиксированными `provider=custom` и
