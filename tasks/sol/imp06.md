`docs/TZ/CRON_IDENTITY_GATE_5_3A.md` и рунбук deploy/), 5 production jobs

## Что сделать
1. Внешние данные (backend, MCP read-only tools с кэшем в БД/файле):
   - погода Ташкент — OpenWeather (ключ в secrets, не в git);
   - намаз Ташкент — Aladhan API, метод Hanafi;
   - новости — источник(и) согласовать с заказчиком в чате до имплементации:
     предложи 2–3 бесплатных варианта с узбекским/русским контентом;
     3–5 пунктов, кириллица, без тревожных тем.
   Кэш: погода/намаз ≥1 раз в сутки достаточно; при недоступности API —
   вчерашние данные с честной пометкой, без выдумывания.
2. Cron jobs (Hermes cron + trusted mapping, по одному deliver на job):
   - утро (время согласовать): приветствие, погода, намаз-времена, план дня
     (обязательства due сегодня/скоро из `get_recurring_obligations`), новости;
   - вечер: мягкий вопрос про расходы дня, если данных за день нет —
     без навязчивого повтора;
   - напоминания об обязательствах: заранее, в due date, один раз мягко после
     просрочки; стоп после paid; без дублей (гейт по `get_recurring_obligations`,
     мутаций в этих jobs нет);
   - разовые «эртага 10 да эслат»: через SOUL-инструкцию — Мариям создаёт
     one-shot cron job моделью (`cronjob` tool). ВНИМАНИЕ: такие jobs untrusted
     (нет в mapping) — им нельзя user-scoped tools; напоминание должно быть
     чистым текстом. Проверить, что это работает и безопасно.
3. SOUL: минимальный diff (правила утро/вечер/напоминаний, «не из головы» для
   погоды/намаза — только из tools), новый SHA синхронно, regression.
4. Mapping: новые trusted jobs по процедуре (fingerprints, allowlists строго
   read-only). Deploy controlled: backup, restart только затронутого,
   rollback описан.
5. E2E controlled (ручной запуск + минимум один штатный тик):
   утро/вечер/напоминание — чистая кириллица, тест-аккаунт; «эртага 10 да
   эслат» → напоминание пришло вовремя; API-недоступность → деградация с
   пометкой. Cleanup тестовых обязательств.
6. Evidence `docs/EVIDENCE_STAGE_6_CRON_<дата>.md`; README/ROADMAP
   (Stage 6 = CLOSED при полном PASS, иначе честный PARTIAL с остатком).
