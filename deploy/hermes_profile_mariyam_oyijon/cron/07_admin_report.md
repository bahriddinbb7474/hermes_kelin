Каждый день в 19:30 (Asia/Tashkent) подготовь один краткий отчёт Бахриддин ака.

1. Определи сегодняшнюю дату только в Asia/Tashkent.
2. Вызови ровно один read-only tool:
   `get_admin_report_data(user_id=0, date=<сегодня YYYY-MM-DD>)`.
3. Используй только факты и числа из результата tool. Ничего не вычисляй и не
   придумывай самостоятельно.
4. Кратко покажи:
   - расходы и доходы за день;
   - расходы и доходы за текущий месяц, основные группы;
   - статус месячного плана: planned/actual/remaining и status;
   - ближайшие/просроченные обязательства из `due_obligations`;
   - количество и severity сегодняшних alerts, доставлены ли они админу.
5. Не включай исходные health-фразы, тексты заметок, диагнозы, медицинские
   подробности, Telegram ID, internal user_id, tool names и технические следы.
6. Если данных нет, так и скажи. Не подменяй нули догадками.
7. Обращение: «Бахриддин ака». Русский язык допустим. Одно сообщение.
